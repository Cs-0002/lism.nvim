# lism.nvim
`lism.nvim` highlight a Common Lisp code.


https://github.com/user-attachments/assets/68a36705-b7c7-4c4d-b421-e0d9482dbbf8

## Installation
Use your package manager. For example, using lazy:
```
{
  "cs-0002/lism.nvim",
  opts = {
    -- saturation = 50,
    -- lightness = 20
  },
}
```
